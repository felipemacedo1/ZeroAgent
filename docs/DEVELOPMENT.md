# Development

Python 3.11+. No runtime third-party dependencies. Run unittest with `PYTHONPATH=src`.
Read context documents and the current Issue before making a branch. Keep deterministic
validation outside model authority. Never add a provider price without dated evidence.
Use Decimal strings or integer micro-units for money; preserve ambiguous reservations.
Review both current tree and all Git history before publishing secrets-sensitive work.

Roadmap: v0.1 executor; v0.2 router/capabilities/metrics; v0.3 measured independent
validator; v0.4 low-frequency coordinator; v0.5 single-vs-multi benchmark; v1 crash
recovery, multiple projects, Projects integration and operational autonomy.
